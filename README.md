# 1Fi Marketplace

## Overview

This project is a React Native/Expo implementation of the **1Fi Marketplace** feature for the 1Fi SDE Intern Assignment. It adds a fully functional marketplace section within the existing Shop experience.

## Features

- **Shop Screen** with three options: Top Brands, Nearby Stores, and 1Fi Marketplace
- **Product Listing** with 2-column grid, images, prices, and EMI information
- **Product Details** with variant selection and EMI plan selection
- **Multi-variant Selection** (e.g., Color + Storage)
- **EMI Plan Selection** with 0% interest badges
- **Confirmation Screen** showing selected product, variants, and EMI plan
- **Loading, Error, and Empty States** with retry functionality
- **Pull-to-Refresh** on product listing
- **Responsive Design** for different screen sizes
- **Accessibility** support with proper roles and labels

## Tech Stack

- React Native (Expo)
- JavaScript (no TypeScript for simplicity)
- React Navigation (Bottom Tabs + Stack)
- React Hooks
- Expo Vector Icons
